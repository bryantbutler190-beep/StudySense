# StudySense Project Plan

## Overview
StudySense is a machine learning application written in C++ that predicts the productivity level of a student's study session based on several study-related factors.

## Problem Statement
Students often struggle to understand which study habits lead to productive study sessions. This project aims to identify patterns in study behavior and predict productivity levels.

## Objectives
- Learn machine learning by implementing algorithms from scratch.
- Practice object-oriented programming in C++.
- Build a complete AI application without external ML libraries.
- Create a portfolio-quality project.

## Input Features
- Study duration
- Hours of sleep
- Number of breaks
- Phone usage
- Subject difficulty
- Previous quiz score
- Energy level
- Time of day

## Output
Predict one of three productivity levels:
- Low
- Medium
- High

## Machine Learning Approach
The first version will use the K-Nearest Neighbors (KNN) algorithm implemented entirely in C++.

## Evaluation
The model will be evaluated using:
- Accuracy
- Confusion Matrix
- Precision
- Recall

## Future Improvements
- Decision Tree
- Neural Network
- Graphical User Interface
- Larger datasets
